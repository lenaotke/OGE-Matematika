# OGE Matematika

Сайт: https://lenaotke.github.io/OGE-Matematika/

В банке 3884 задания ФИПИ с решениями. Для быстрой работы карточки загружаются страницами до 10 заданий. Повторяющиеся изображения вынесены в отдельные файлы и загружаются по мере просмотра.

На телефоне используйте кнопку «Фильтр и карточки» или список «Номер или тема». Поиск работает по всему банку; проверенные ответы сохраняются в браузере.

## Файлы и публикация

- `site.zip` — рабочая версия сайта: `index.html`, `app.js`, `answers.js`, `styles.css`, `manifest.json`, `search.json`, папки `pages/` и `assets/`.
- `.github/workflows/pages.yml` распаковывает `site.zip` и публикует содержимое через GitHub Pages.
- `index.html.gz` — сохранённая исходная монолитная версия до оптимизации, не используется при публикации.

Для локального просмотра распакуйте `site.zip` и запустите в его папке `python -m http.server 8000`. Откройте http://localhost:8000/. Для обновления замените файлы в архиве, загрузите новый `site.zip` в репозиторий; публикация запустится автоматически.

Ссылки на ФИПИ и вспомогательные файлы `fipi_links_by_number.csv` и `fipi_green_highlight.user.js` сохранены. Подсветка на внешнем сайте ФИПИ требует установки пользовательского скрипта через Tampermonkey или Violentmonkey.
