# ОГЭ-2027: банк заданий ФИПИ

Откройте `index.html` локально или разместите содержимое этой папки в GitHub Pages. Все изображения и MathML встроены в HTML, поэтому отдельный сервер для условий не нужен.

## Ссылки

В каждой карточке ссылка строится по видимому номеру ФИПИ и странице выгрузки, например:

`https://oge.fipi.ru/bank/questions.php?proj=DE0E276E497AB3784C3FC4CC20248DC0&page=14&pagesize=10#q37EB4D`

Всего проверено 3884 карточки; таблица соответствий находится в `fipi_links_by_number.csv`.

## Зеленое выделение

GitHub Pages не может изменить DOM/CSS страницы `oge.fipi.ru`: это ограничение браузеров (same-origin policy). Поэтому `index.html` подсвечивает карточку зеленым перед переходом, а `fipi_green_highlight.user.js` подсвечивает найденный блок уже на ФИПИ.

Для автоматической рамки на ФИПИ установите `fipi_green_highlight.user.js` через Tampermonkey или Violentmonkey. После установки рамка появляется автоматически при открытии ссылок с `#qXXXXXX`. Без расширения ссылка все равно открывает правильное задание, но внешняя страница не может быть стилизована вашим GitHub-сайтом.
